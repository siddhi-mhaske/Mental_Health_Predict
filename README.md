# Mental Health Score Predictor

# Problem :
Student Mental Health Score Prediction is a Machine Learning project that predicts a student's Mental Health Score based on various academic, lifestyle, and social-media usage factors.

# 🛠️ Technologies Used
Programming Language : Python
Machine Learning : Scikit-learn , Pandas , NumPy
Data Visualization : Matplotlib , Seaborn
Backend : FastAPI , Uvicorn
Frontend : HTML , CSS , JavaScript
Development Tools :  Jupyter Notebook , Visual Studio Code 
Version Control : Git , GitHub
Deployment : The FastAPI application can be deployed on a cloud platform such as Render.
